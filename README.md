## House Prices

### Как использовать

1. `pip install -r requirements`
2. `python -m main` для запуска подбора Optuna и/или обучения модели нейросети/бустинга. Режим можно настроить в config.yaml.
3. `python -m other_models` для проверки на прочих моделей (Регрессия, KNN, одиночное дерево, Random Forest)
4. Результаты оптимизации (конфиг, графики) и обучения (модель) логируются mlflow, файл Optuna studies сохраняется в **outputs/**
### Настройка конфига перед запуском
Файл config.yaml уже содержит лучшие гиперпараметры, подобранные в ходе оптимизации Optuna. 

**Выбор режима запуска в result**
Для запуска оптимизации Optuna: result - mode - study - *true*
Для запуска обучения модели по параметрам из конфига/полученным из Optuna: result - mode - train - *true*

**Data:**
pipeline: выбор пайплайна sklearn для подготовки данных (*linear* для torch и прочих моделей/*boosting* для бустингов). 
**log_transform_target**: логарифмирование таргета (для регрессии)

**Model choosing:**
Выбор модели для оптимизации и обучения.

**Optuna:**
**n_trials**: количество запусков. 
**metric**: оптимизируемая метрика (можно редактировать список в metrics.py). 
**num_iterations_strategy**: выбор количества эпох/деревьев для финальной модели при кросс-валидации. 

### Подход и результаты:
Данные были разделены на 80% train и 20% test выборки. 
1) На train выборке проводилась подбор гиперпараметров Optuna через оптимизацию OOF метрики по 5 фолдам (в данном соревнование метрикой был RMSLE). 
2) Далее обучалась предфинальная модель на train выборке и получалась метрика на test выборке. 
3) Финальная модель, обученная на всех данных валидировалась на Kaggle. В итоге для моделей были получены 3 результата.

| Model    | OOF RMSLE (CV=5, метрика <br>для оптимизации Optuna) | Test RMSLE (on <br>20% test dataset) | Kaggle RMSLE |
| -------- | ---------------------------------------------------- | ------------------------------------ | ------------ |
| CatBoost | 0.12300                                              | 0.12785                              | 0.12777      |
| XGB      | 0.12465                                              | 0.13321                              | 0.12261      |
| LGBM     | 0.12363                                              | 0.13326                              | 0.12420      |
| Torch    | 0.13380                                              | 0.14189                              | 0.13244      |

Как видно, нет какой-то зависимости между OOF метрикой, метрикой на тесте и на Kaggle. Из замеченного только то, что torch дал чуть худшие результаты на табличных данных, чем бустинги.
